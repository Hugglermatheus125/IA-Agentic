# Stack Tecnologica

## Decisoes

- **Linguagem:** TypeScript.
- **Frontend:** React com Vite.
- **Banco de dados inicial:** SQLite, de forma provisoria.
- **Conteudo:** cursos tecnicos e matrizes curriculares conforme a referencia indicada pela coordenacao; materias ainda indisponiveis podem usar dados simulados temporarios.

## Pontos a definir

- Escolher a tecnologia de servidor e a API que conectarao a aplicacao ao SQLite. O acesso ao banco deve ocorrer no servidor, nunca diretamente no navegador.
- Definir a estrategia de autenticacao e autorizacao para a equipe que cadastra noticias.
- Rever a escolha do banco quando os requisitos de hospedagem e operacao estiverem claros.
